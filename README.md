# Employee Management System SQL Project

## Project Overview

This project demonstrates database design and business analysis using PostgreSQL.

## Database Tables

* Departments
* Employees
* Projects
* Employee_Project

## Concepts Used

* Primary Keys
* Foreign Keys
* Joins
* Self Joins
* GROUP BY
* HAVING
* Subqueries
* Correlated Subqueries
* CTEs
* Window Functions

## Key Analyses

* Highest Paid Employee
* Manager with Most Employees
* Employees Working on Multiple Projects
* Department Salary Analysis
* Project Budget Analysis
* Employee Rankings

* PostgreSQL
